Git Command Center

Essential commands for your practical assignment.

01 / INITIALIZATION

Initialize Git

Create a local Git repository.

git init
02 / STAGING

Add Files

Stage project files for committing.

git add .
03 / COMMIT

Save Changes

Create a meaningful commit.

git commit -m "Initial commit"
04 / BRANCHING

Create Branch

Create a separate feature branch.

git switch -c feature
05 / BUG FIX

Commit Bug Fix

Save your bug fix with a clear message.

git commit -am "Fix bug"
06 / PUBLISH

Push Branch

Upload your branch to GitHub.

git push -u origin HEAD

Developer Best Practices

Build habits that make your repository professional.

✦ Meaningful Commits

Use descriptive messages such as "Add responsive navigation" instead of "update".

⑂ Feature Branches

Keep new features and bug fixes separate from the main branch.

◎ Pull Request Reviews

Explain what changed and why before merging your contribution.

✓ Issue Tracking

Document bugs, track solutions and link issues with pull requests.
